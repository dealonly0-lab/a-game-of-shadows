# HOLLOW

A top-down 2D browser survival game prototype built with Phaser 3, TypeScript, and Vite.

## Concept

HOLLOW is set in a haunted village where darkness is safety and light is danger. Players are hard to see in darkness, but stepping into light exposes their shadow. A player can only be eliminated while their shadow is visible, using a beam of light.

Core hook:

> Don't step in the light.

## Current Status

This is an early foundation prototype. It is not a finished game.

Current systems:

- Phaser 3 rendering
- TypeScript simulation layer
- haunted village tile map
- light sources and darkness overlay
- shadow exposure state
- beam shooting
- basic bot opponents
- dawn progression
- debug overlay with `F1`

## Development

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Build:

```bash
npm run build
```
